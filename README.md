# LIHTO Studio — GitHub Pages

A ready-to-publish, responsive single-page website. No build steps, dependencies, or paid hosting required.

## Before uploading

1. Open `index.html` and replace **`YOUR_EMAIL@example.com`** (both occurrences) with your actual support email.
2. Optionally update the About text to match products you have really built; do not add fictitious product claims.

## Publish (personal GitHub Pages site)

1. Create a **public** GitHub repository named exactly `YOUR_USERNAME.github.io` (replace YOUR_USERNAME with your actual GitHub username).
2. Upload `index.html`, `.nojekyll`, and the `assets` folder to the root of the repository on the `main` branch. Upload the **contents** of this folder, not the outer folder and not the `.zip` itself.
3. Open repository **Settings → Pages**; choose **Deploy from a branch**, then **main** and **/(root)**; click **Save**.
4. Your website address will be `https://YOUR_USERNAME.github.io/` after publishing completes.

If you instead name the repository `lihto-studio`, your site address will be `https://YOUR_USERNAME.github.io/lihto-studio/`.

GitHub Pages documentation: https://docs.github.com/en/pages/quickstart
